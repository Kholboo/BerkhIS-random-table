# Ангийн суудлын зохион байгуулалт

Сурагчдыг ширээнд санамсаргүй хуваарилдаг вэб хуудас. Сурагчдын зураг, жагсаалт, суудлын хуваарилалт **сервэрт** хадгалагдана.

## Ажиллуулах

Node.js 16+ шаардлагатай. Гадны сан суулгах шаардлагагүй.

```bash
git clone <repo-url>
cd <repo-folder>
npm start        # эсвэл: node server.js
```

Дараа нь хөтчөөр http://localhost:3000 хаягаар нээнэ. Өөр порт ашиглах бол `PORT=8080 npm start`.

## Бүтэц

```
server.js          Сервэр (статик файл + API)
public/index.html  Вэб хуудас
photos/            Сурагчдын зураг (git-д орохгүй)
data/state.json    Жагсаалт, тохиргоо, хуваарилалт (git-д орохгүй)
```

## Зураг

- "Нэр & Зураг засах" цонхоор зураг оруулахад `photos/` хавтсанд хадгалагдана.
- Эсвэл зургаа `photos/` хавтсанд шууд хийж болно. Файлын нэр сурагчийн **нэр** (`Анар.jpg`) эсвэл **id** (`f2.jpg`)-тай таарвал автоматаар харагдана. Дэмжих төрөл: jpg, png, webp, gif.

## API

| Метод | Зам | Үүрэг |
|-------|-----|-------|
| GET | `/api/state` | Хадгалсан төлөв + зургийн жагсаалт |
| PUT | `/api/state` | Төлөв хадгалах |
| POST | `/api/photos/:id` | Зураг оруулах (jpg/png/webp) |
| DELETE | `/api/photos/:id?name=` | Зураг устгах |

## Анхаарах зүйл

- Нэвтрэлт байхгүй. Сервэрт хандах хүн бүр засварлах боломжтой тул нээлттэй интернэтэд гаргахаасаа өмнө нууц үг эсвэл reverse proxy-ийн хамгаалалт нэмнэ үү.
- Зургууд болон `data/` хавтас `.gitignore`-д орсон тул сурагчдын мэдээлэл GitHub руу очихгүй.
- GitHub Pages зэрэг статик хостинг дээр ажиллахгүй, учир нь Node.js сервэр шаардлагатай (VPS, Render, Railway, өөрийн компьютер гэх мэт).
