# Ангийн суудлын зохион байгуулалт

Сурагчдыг ширээнд санамсаргүй хуваарилдаг вэб хуудас. Сурагчдын зураг, жагсаалт, суудлын хуваарилалт **сервэрт** хадгалагдана.

## Ажиллуулах

Node.js 16+ шаардлагатай. Гадны сан суулгах шаардлагагүй.

```bash
git clone <repo-url>
cd <repo-folder>
npm start        # эсвэл: node server.js
```

Дараа нь хөтчөөр http://localhost:3000 хаягаар нээнэ. Өөр порт ашиглах бол `PORT=8080 npm start`.

## Бүтэц

```
server.js          Сервэр (статик файл + API)
public/index.html  Вэб хуудас
photos/            Сурагчдын зураг (git-д орохгүй)
data/state.json    Жагсаалт, тохиргоо, хуваарилалт (git-д орохгүй)
```

## Зураг

- "Нэр & Зураг засах" цонхоор зураг оруулахад `photos/` хавтсанд хадгалагдана.
- Эсвэл зургаа `photos/` хавтсанд шууд хийж болно. Файлын нэр сурагчийн **нэр** (`Анар.jpg`) эсвэл **id** (`f2.jpg`)-тай таарвал автоматаар харагдана. Дэмжих төрөл: jpg, png, webp, gif.

## Зургийг вэб линкээс унших

"Нэр & Зураг засах" цонхонд:

- Сурагч бүрийн мөрөн дэх 🔗 товчоор тухайн сурагчийн зургийн линкийг (`https://...jpg`) оруулна. Google Drive-ийн "хуваалцах" линкийг шууд хүлээн авна (файл "Холбоостой хэн ч үзэж болно" байх ёстой).
- Доод талын **Зургийн хаяг** товчоор бүх сурагчид нэг загвар өгч болно: `https://example.com/photos/{name}.jpg` (`{name}` = сурагчийн нэр, `{id}` = id).
- Линк ажиллахгүй бол энгийн дүрс харагдана. HTTPS сайт дээр `http://` линк хөтчөөр хаагдана.

Зургийн дараалал: энэ хөтөч дээр оруулсан зураг → сурагчийн линк → `photos/` хавтсын файл → хаягийн загвар.

## API

| Метод | Зам | Үүрэг |
|-------|-----|-------|
| GET | `/api/state` | Хадгалсан төлөв + зургийн жагсаалт |
| PUT | `/api/state` | Төлөв хадгалах |
| POST | `/api/photos/:id` | Зураг оруулах (jpg/png/webp) |
| DELETE | `/api/photos/:id?name=` | Зураг устгах |

## GitHub Pages дээр байрлуулах (сервэргүй, өгөгдөл GitHub-д хадгалагдана)

Сервэр байхгүй үед хуудас өөрөө GitHub repo-г өгөгдлийн сан болгон ашиглана:

- Хуваарилалт, жагсаалт, тохиргоо → `data/state.json` (commit хийгдэнэ)
- Зураг → `photos/` хавтас (нэр эсвэл id-аар нэрлэгдсэн)

**1. Байрлуулах**
1. Repo руу push хийнэ.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Actions дууссаны дараа `https://<нэр>.github.io/<repo>/` хаягаар нээнэ.

**2. Засварлах эрх (багш)**
1. GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. *Repository access* → зөвхөн энэ repo. *Permissions → Repository permissions → Contents: Read and write*.
3. Сайт дээрх **GitHub** товчийг дараад repo (`owner/repo`) болон токеноо оруулна. Токен зөвхөн тухайн хөтөч дээр хадгалагдана.

Токен оруулсан хөтөч засварлаж, GitHub-д хадгалж чадна (өөрчлөлт бүр commit болно). Токенгүй хүн (сурагч г.м.) зөвхөн хадгалагдсан хуваарилалтыг харна, шинэчлэлт 5 минут хүртэл саатаж болно.

Анхаарах:
- Нэг зэрэг хоёр хөтөчөөс хадгалбал сүүлийнх нь давамгайлна.
- Хадгалалт бүр commit болдог тул компьютерээсээ push хийхийн өмнө `git pull --rebase` хийнэ.
- Токеныг зөвхөн итгэмжлэгдсэн компьютер дээр оруулна, нэг repo-д хязгаарлана.
- GitHub Pages сайт, public repo нийтэд нээлттэй: сурагчдын нэр, зураг бүгдэд харагдана.

## Сервэр дээр өгөгдөл хадгалагдахгүй байвал

Хуудасны толгой хэсгийн төлөвийг харна уу:

- **"Сервэрт хадгалагдсан"** (ногоон): хэвийн.
- **"Сервэр олдсонгүй: зөвхөн энэ хөтөч дээр хадгалагдсан"** (шар): хуудас `node server.js`-ээр биш, зүгээр статик файл болж үйлчилж байна. Хостинг дээр Node.js ажиллаж байх ёстой, `/api/health` хаяг нээгдэх ёстой.
- **"Хадгалж чадсангүй"** (улаан): сервэр ажиллаж байгаа ч `data/` хавтсанд бичих эрхгүй. `/api/health` дээр `dataWritable: false` гарна.

Хадгалсан мэдээлэл дахин ачаалахад устдаг бол (Render/Heroku-ийн үнэгүй багц, Docker контейнер г.м.) хостингийн файлын систем түр зуурынх байна гэсэн үг. Байнгын диск (volume) холбож, замыг нь зааж өгнө:

```bash
DATA_DIR=/var/data/seating PHOTO_DIR=/var/data/photos node server.js
```

## Нууц үг

"Санамсаргүй хуваарилах" болон "Нэр & Зураг засах" товчийг дарахад нууц үг асууна.

- Анх удаа дарахад шинэ нууц үг тохируулна. Нууц үгийг "Нэр & Зураг засах" цонхны доод талын **Нууц үг** товчоор солино.
- Нууц үг өөрөө хадгалагдахгүй, давстай PBKDF2 хэш нь `data/state.json` дотор (`auth`) хадгалагдана. GitHub горимд энэ нь repo-д commit болно.
- Нэвтэрсэн төлөв зөвхөн тухайн табд (sessionStorage) үлдэнэ.
- Нууц үгээ мартвал repo дахь `data/state.json`-оос `"auth"` хэсгийг `null` болгож засна (эсвэл Node сервэрийн `data/state.json`-д).
- Энэ нь интерфэйсийн түгжээ юм. Public repo-д хэш харагддаг тул хялбар нууц үгийг таах боломжтой, урт нууц үг сонгоно уу. Нийтлэг байдлаар өгөгдлийг жинхэнэ хамгаалдаг зүйл нь GitHub токен юм (токенгүй хүн хадгалж чадахгүй).
- HTTPS эсвэл localhost дээр л ажиллана (хөтчийн crypto API шаардлага).

## Анхаарах зүйл

- Node сервэрийн горимд нэвтрэлт байхгүй, сервэрт хандах хүн бүр засварлах боломжтой.
- GitHub Pages сайт нийтэд нээлттэй байдаг (private repo-д Pages ашиглахад төлбөртэй багц хэрэгтэй). Сурагчдын нэр, зураг `photos/` болон `public/index.html`-д орсон тул оруулахаасаа өмнө эдгээрийг нийтэд харуулах эсэхээ шийднэ үү.
